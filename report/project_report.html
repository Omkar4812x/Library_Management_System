Chapter 1

Introduction

1.1 Background

A library is one of the most vital information hubs in any educational institution. It houses hundreds to thousands of books, journals, magazines, and digital resources. Managing these resources manually using paper registers is not only time-consuming but also highly error-prone and inefficient.

With the rapid advancement of information technology, automating library operations has become essential for institutions of all sizes. A Library Management System (LMS) is a software application that automates the core functions of a library — including cataloguing books, managing member records, issuing and returning books, tracking overdue books, and generating comprehensive reports.

1.2 Problem Statement

Problem: Traditional library management relies on manual record-keeping in physical registers. This leads to:
  • Difficulty in locating specific books quickly
  • Manual errors in issue/return records
  • No automated tracking of overdue books or fines
  • Time-consuming generation of reports
  • Loss or damage of paper records
  • Inability to search across hundreds of records instantly

1.3 Proposed Solution

LibraX is a modern, web-based Library Management System designed to solve all of the above problems. It provides a fully digital, user-friendly interface for managing library operations with real-time data persistence, instant search, and automated fine calculation.

✅ LibraX Key Highlights:
  • Full-stack web application with PHP backend and MySQL database (XAMPP)
  • Secure PHP session-based login with MD5 password hashing
  • Complete Book & Member management (CRUD) via RESTful PHP API
  • Automated book issue/return with due date tracking & fine payment tracking
  • Auto fine calculation at ₹2 per day for overdue books
  • Book Reservation system for fully issued books
  • CSV export for all tables and reports
  • Overdue notifications bell in real-time
  • Member borrowing history modal
  • Dark & Light mode toggle (persistent)
  • Real-time reports & printable outputs
  • Data persisted in MySQL database via PDO
  • Modern responsive UI with glassmorphism & animations

3.1 Existing System

Most small-to-medium libraries in educational institutions in India still use manual systems for day-to-day operations. The librarian maintains physical registers for book records, member records, and issue/return entries. Reports are generated manually at the end of each month.

Disadvantages of Existing System:

  • Time-consuming search through physical registers
  • Human errors in data entry and calculations
  • No real-time availability status of books
  • Difficult to track overdue books across hundreds of members
  • Reports require significant manual effort
  • Data loss risk due to physical damage of records

The proposed LibraX system replaces the manual workflow with a digital, web-based solution that:

  • Provides real-time book availability status
  • Automates overdue detection and fine computation
  • Generates reports with a single click
  • Allows instant global search across all records
  • Runs on any device with a web browser

7.2 Key Implementation Details

7.2.1 Data Persistence

All data is stored in a MySQL relational database (librax_db) running on XAMPP. The PHP backend uses PDO with prepared statements for secure, parameterized queries. The database contains 5 tables (users, books, members, transactions, reservations) with proper foreign key constraints, and 2 views for overdue reporting. Auto-increment counters generate unique codes (B001, M001, T001, R001).

7.2.2 Fine Calculation Logic

The fine is calculated automatically during book return:

Formula: Fine = Max(0, (Today − Due Date in days)) × ₹2 per day

Example: If a book was due on Oct 10 and returned on Oct 20, the overdue days = 10, fine = ₹20.

7.2.3 Overdue Detection

Every time the application loads, it scans all active transactions and marks any whose due date has passed as "Overdue". This ensures the system always reflects the current state accurately.

7.2.4 Data Integrity Guards

  • Books currently issued cannot be deleted
  • Members with active book issues cannot be deleted
  • A member cannot issue the same book twice
  • Duplicate member emails are rejected
  • Only available books appear in the issue dropdown

Conclusion

The LibraX Library Management System successfully demonstrates the development of a fully functional, full-stack web application using HTML5, CSS3, JavaScript for the frontend and PHP + MySQL for the backend — running on XAMPP.

The project effectively digitizes and automates the core operations of a library: book cataloguing, member management, book issue/return, overdue tracking, fine calculation & payment, book reservation, comprehensive reports, and real-time notifications. The system features 20+ functional capabilities, a modern dual-theme UI, and a properly designed relational database with 5 tables and foreign key constraints.
